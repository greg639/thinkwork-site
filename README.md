# thinkwork.info

Static site for ThinkWork: websites and money-making systems for local businesses
(relaunch, September 2026). Deployed via GitHub Pages: pushing `main` publishes it.

- Pages are generated by `_src/build.py` (shared header, footer, plans, ideas board).
  Edit there, then run `python3 _src/build.py`. Don't hand-edit the generated `index.html` files.
- `/airsoft/` is a separate property built from `_src/airsoft.html`: its own look, and no
  links to or from the main site.
- Forms post cross-origin to `https://app.peerlab.ai/api/thinkwork/quote`.
- The chat widget is written but off (`CHAT_ENABLED` in `static/tw/site.js`) until a backend exists.
- `/assurance/`, `/speaking/`, `/thinkwork/letter/`, `/greg/` and the `/blog/` + `/library/`
  move-stubs are left as they were.
