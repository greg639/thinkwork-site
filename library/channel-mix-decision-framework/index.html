Channel Mix Decision Framework (Email vs LinkedIn vs Call vs Video)

A decision tree for which channel to lead with — by segment, persona seniority, and signal warmth — so channel choice is a system, not rep instinct.

What's inside

  • Segment-first branch: Enterprise / Mid-Market / SMB
  • Persona-tier branch: C-suite/VP, Director/Manager, IC/Champion
  • Warm-signal vs cold-signal branch at each persona tier
  • Full decision tree in text form, worked for all 9 segment×persona combinations
  • Quick-reference lead/second/avoid-leading-with matrix table
  • 1 signal-override rule that beats the segment default

Channel choice should follow three inputs, checked in this order: segment, persona seniority, and signal warmth (whether you have a real reason to believe this account is primed — a referral, a mutual connection, inbound engagement, or a recent trigger event).

Step 1: Segment

  • Enterprise (large org, high ACV, long cycle, multiple stakeholders) → go to Enterprise branch
  • Mid-Market → go to Mid-Market branch
  • SMB (small org, fast cycle, single or near-single decision-maker) → go to SMB branch

Enterprise branch

C-suite / VP:

  • Warm: Lead with a personalized video message → follow with email framed around business-level ROI → LinkedIn as a supporting social-proof touch → reserve a call attempt for after 2+ touches have landed
  • Cold: Spend 1–2 weeks on LinkedIn engagement (thoughtful comments, no ask) before any direct outreach → then email → then video → call last, and only after some response

Director / Manager:

  • Warm: Email first (specific, short) → call second → LinkedIn running in parallel as reinforcement
  • Cold: Email + LinkedIn connection request in parallel → call as the third touch once there's some familiarity

IC / Champion (technical buyer, influencer):

  • Warm: LinkedIn message first — this level accepts a more casual channel — email second
  • Cold: LinkedIn first, email second, call rarely the lead channel at this tier

Mid-Market branch

VP / Director:

  • Warm (referral-sourced): Call first
  • Cold: Email first, call second — higher call tolerance than Enterprise at this level — LinkedIn running in parallel

Manager / IC:

  • Warm: Call first
  • Cold: Email and call both in week 1, LinkedIn as an amplifying touch rather than a lead channel

SMB branch

(Usually a single or near-single decision-maker; fast cycle, fewer stakeholders to multi-thread.)

  • Warm: Call immediately
  • Cold: Call-first is typically highest ROI given cycle speed and stakeholder count — email as a pre-call and post-call touch, LinkedIn as light-touch only

Signal-override rule

At any segment or tier: if the persona has posted or commented publicly about the exact problem you solve within the last 30 days, lead with a LinkedIn comment or reply on that thread instead of the default channel. A relevant, specific comment on something they said themselves outperforms cold volume on any channel — this override beats the segment default every time it applies.

How to use it

Start at the segment branch for the account you're working, follow it down through persona seniority and signal warmth to get a lead channel and second channel, then check the override rule before finalizing — it beats the default whenever it applies.
