Call Observation Notes Template

A structured note-taking sheet for live or recorded call observation that forces a specific behavior, a verbatim quote, and a named coaching point per call — instead of a vague post-call impression.

What's inside

  • Call context fields (rep, date, call type, stage)
  • Repeatable behavior-quote-coaching-point row structure
  • Skill/competency tag field per observation
  • Strength-to-reinforce field
  • Growth-edge-to-address field
  • One-thing-for-next-call commitment field
  • Manager overall rating field
  • Fully filled-in worked example

A post-call impression ("that went pretty well") is not coaching data. This template forces three things for every observation: the specific behavior, the rep's actual words, and a named coaching point tied to a skill — filled in during the call, not reconstructed from memory an hour later.

How to use it

Keep this open while observing a live call or scrubbing through a recording, fill in at least 2-3 behavior rows during the call itself rather than reconstructing from memory afterward, and use the one-thing-for-next-call field as the entire agenda for the follow-up 1:1.
