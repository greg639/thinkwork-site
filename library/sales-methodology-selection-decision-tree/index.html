Sales Methodology Selection Decision Tree

A branching decision tree that turns deal size, buying-committee size, sales-cycle length, and market maturity into a recommended methodology or blend.

What's inside

  • Full branching decision tree keyed on ACV, stakeholder count, cycle length, and market maturity
  • The two-axis model explaining why every branch resolves to a qualification layer plus a conversation layer
  • Numeric scoring matrix with 4 weighted dimensions
  • Score-to-zone mapping table
  • Named blend table with 'use when' triggers for each combination

Answer four questions about your motion. Get a starting methodology (or blend) — not a religious commitment, a starting point to test.

The tree

`` START │ ├─ Q1: Average deal size (ACV)? │ ├── Under $10k │ └─ Q2: Sales cycle under 30 days AND 1–2 stakeholders? │ ├── YES → SANDLER (fast disqualification, objection handling, minimal process overhead) │ └── NO → SPIN + light MEDDIC (Metrics + Champion only) │ ├── $10k–$50k │ └─ Q2: 2–4 stakeholders, cycle 1–3 months? │ ├── YES → SPIN (discovery technique) + MEDDIC-lite (Metrics, Economic Buyer, Champion) │ └── NO, fewer stakeholders/shorter cycle → SANDLER │ ├── $50k–$250k │ └─ Q2: 3–6 stakeholders, cycle 3–9 months? │ ├── YES, and market is crowded/commoditized → CHALLENGER (Teach/Tailor) + full MEDDIC │ └── YES, but market is novel/uneducated → SPIN-led discovery + full MEDDIC │ └── $250k+ └─ Q2: 5+ stakeholders, cycle 9+ months, procurement/security/legal review expected? ├── YES → MEDDPICC + COMMAND OF THE MESSAGE └── Public sector / formal RFP → MEDDPICC (Paper Process is non-negotiable), regardless of size ``

The two axes underneath the tree

Every branch above is really answering two independent questions:

  1. How real is this deal, and will it survive procurement? → answered by the qualification layer: MEDDIC → MEDDPICC as stakeholders, cycle length, and procurement rigor increase.
  2. How do we actually run the conversation and differentiate? → answered by the conversation layer: SPIN → Challenger → Command of the Message as market crowding and rep-population scale increase, with Sandler as the alternative when speed/disqualification matters more than insight-selling.

You always pick one from each axis. The tree above just tells you where to start on each.

How to use it

Walk your motion through the tree top to bottom, or use the numeric scoring matrix if your deals don't fit one branch cleanly, then check the named-blend table for how to combine a qualification layer with a conversation layer.
