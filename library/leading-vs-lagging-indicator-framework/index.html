Leading vs Lagging Indicator Framework

A three-tier hierarchy connecting daily activity to pipeline conversion to revenue outcomes, with a diagnostic method for finding and coaching the number that actually moves first.

How to use it

When any revenue or attainment number is off plan, run it through the decision tree before your next 1:1 with the rep, and coach only the earliest tier the tree identifies as broken.

What's inside

  • The three-tier hierarchy: Activity, Conversion, Outcome
  • Definitions and example metrics for each tier
  • Time horizon for when each tier's signal shows up
  • The core coaching rule: always coach the earliest broken tier

Coach the number that moves first, not the number that moves last

Most sales managers manage the lagging number: bookings, attainment, revenue, because it's the one on the dashboard everyone stares at. But you can't coach a lagging number directly. By the time it's off, the cause happened weeks or months earlier, upstream. This framework gives you the hierarchy and the diagnostic method to find where the problem actually started.

The Three Tiers

Tier 1: Activity (Leading)

What it is: The behaviors a rep fully controls, every day, regardless of market conditions. Example metrics: Dials, connects, emails sent, social touches, meetings booked, discovery calls completed, demos delivered, proposals sent. Time horizon: Shows up the same day or same week. This is your earliest possible warning signal. Rep control: Total. If this tier is off, it's a behavior/discipline/capacity issue, full stop.

Tier 2: Pipeline Conversion (Coincident)

What it is: How efficiently Tier 1 activity turns into qualified, advancing pipeline. This tier is influenced by the rep's skill, but also by market and product fit, it's not pure behavior anymore. Example metrics: Meeting-to-opportunity conversion rate, stage-to-stage conversion rate, pipeline created ($), average deal velocity (days per stage), pipeline coverage ratio. Time horizon: Shows up 2–6 weeks after the Tier 1 activity that created it. Rep control: High but not total: this is where skill (discovery quality, qualification rigor, multi-threading) shows up as a number.

Tier 3, Revenue Outcomes (Lagging)

What it is: The result. This is the number the board, the CFO, and the CRO ultimately care about, and the number with the least diagnostic value on its own. Example metrics: Closed-won revenue, win rate, quota attainment, NRR/GRR, ARR growth. Time horizon: 90+ days after the activity that actually caused it. Rep control: Indirect only, you cannot coach "close more deals." You can only coach Tier 1 and Tier 2 behaviors that produce Tier 3 outcomes.

The Coaching Rule

Always coach the earliest tier where the number is broken. Never coach the tier where the number is merely visible.

If Tier 3 is off, the fix is never "try harder to close." It's diagnosing whether Tier 2 (conversion) or Tier 1 (activity) broke first, and coaching that, because that's the only place a rep can actually change behavior starting today.

Diagnostic Decision Tree

Use this every time a revenue number (Tier 3) is off plan:

`` Is Tier 3 (revenue/attainment) below plan? │ ├─ YES → Check Tier 2: Is win rate / conversion rate also below benchmark? │ │ │ ├─ YES, conversion is broken → Check Tier 1: Is activity volume at target? │ │ │ │ │ ├─ YES, activity is fine → Skill/quality problem in Tier 2 │ │ │ (discovery quality, qualification, multi-threading, │ │ │ value articulation). Coach the SKILL, not the volume. │ │ │ │ │ └─ NO, activity is also below target → Behavior/capacity problem │ │ in Tier 1. Coach activity discipline FIRST, fixing Tier 2 │ │ skill won't matter if there isn't enough volume feeding it. │ │ │ └─ NO, conversion rate is fine → Check Tier 1: Is activity volume sufficient │ to produce enough pipeline at current conversion rate? │ │ │ ├─ NO → Simple volume/coverage problem. Coach activity volume. │ │ │ └─ YES → Not a rep-execution problem. Check deal-level factors: │ concentration risk, slipped close dates, market/competitive │ shift. This is a forecast-integrity or market issue, not │ a coaching issue. │ └─ NO → Tier 3 is on plan. Still check Tier 1 and 2 proactively: a rep can be hitting Tier 3 today on pipeline created months ago while Tier 1 has quietly collapsed, which will show up as a miss two quarters from now. ``

Worked Example

Observation: Rep A is at 62% quota attainment (Tier 3 miss) with one month left in the quarter.

Step 1: Check Tier 2: Win rate is 24%, in line with team benchmark of 22–28%. Conversion isn't the problem.

Step 2, Check Tier 1 (since Tier 2 is clean): Rep A booked 3 meetings this month against a target of 10. Pipeline created is 40% of target.

Diagnosis: The problem is Tier 1, activity volume, not skill. Coaching Rep A on discovery technique or negotiation (Tier 2/3 behaviors) would miss the actual cause entirely.

Correct coaching move: Address the activity shortfall directly: is it a capacity issue (too much admin/account management load), a discipline issue (not prioritizing prospecting), or a territory issue (list quality)? The fix lives at Tier 1.

Common Coaching-Rule Violations

  • Coaching the scoreboard: Telling a rep to "close more" or "hit your number" without naming which upstream tier is actually broken.
  • Skipping straight to Tier 2 skill coaching (discovery, objection handling) when the real gap is Tier 1 volume, skill coaching on insufficient volume produces no measurable lift.
  • Ignoring Tier 1 when Tier 3 looks fine: a rep can be living off pipeline built months ago while current activity has quietly cratered; by the time Tier 3 shows it, you've lost a full cycle length of runway to fix it.
  • Treating all Tier 2 metrics as one number, a low meeting-to-opportunity rate and a low stage-3-to-stage-4 rate are different skill gaps (qualification vs. value articulation) and need different coaching.
