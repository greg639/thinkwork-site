Outbound Metrics Dashboard Template

A plug-and-play spreadsheet spec — four tabs, exact column definitions and formulas — for tracking dials, connects, meetings booked, and show rate by rep and by week.

What's inside

  • Tab 1: Daily Activity Log raw input columns
  • Tab 2: Weekly Rep Rollup with rate formulas
  • Tab 3: Team Dashboard with rankings and trend view
  • Tab 4: Benchmarks reference tab
  • Conditional formatting rule set (green/yellow/red thresholds)
  • 15-minute weekly review agenda using the dashboard
  • Data hygiene rules to keep the numbers trustworthy

Build as 4 tabs in one workbook. Rep-level raw data feeds automatically into the rollup and team views.

Tab 3 — Team Dashboard

  • Rep leaderboard sorted by Meetings Booked (primary) and Show Rate (secondary — booking meetings that don't show isn't progress)
  • 4-week trend column per rep per metric (up/flat/down arrow)
  • Team average row pinned at top for comparison
  • Filter by week / month / quarter

Tab 4 — Benchmarks (reference)

Pull target ranges from the Outbound Prospecting KPI Benchmark Guide and paste as a static reference row so reps can self-compare without leaving the sheet.

Conditional formatting rules

MetricRedYellowGreen
Connect Rate< 8%8–15%> 15%
Meeting Set Rate< 10%10–20%> 20%
Show Rate< 65%65–80%> 80%
Opportunity Conversion< 30%30–50%> 50%

(Adjust thresholds to your own benchmark data after 1 full quarter — these are conservative starting points.)

15-minute weekly review agenda (using this dashboard)

  1. (3 min) Team Dashboard — who's red on Show Rate two weeks running (scheduling/qualification issue, not an activity issue)
  2. (5 min) Rep Rollup — anyone with high Dials but low Meeting Set Rate (talk-track issue, not volume issue)
  3. (4 min) Trend arrows — anyone trending down 2+ weeks in a row on any green metric (early warning, not yet a red flag)
  4. (3 min) Assign 1 coaching action per flagged rep, log it, review next week

Data hygiene rules

  • Dials, connects, and meetings must come from system exports (dialer/CRM), never self-reported — self-reported activity data drifts within 2 weeks.
  • Lock the Daily Activity Log tab from manual overwrites; only rollup formulas should touch calculated cells.
  • Reconcile CRM vs. dialer totals monthly — mismatches usually mean a rep is dialing outside the tracked tool.

How to use it

Build the four tabs in a spreadsheet, feed Tab 1 from your dialer/CRM exports, let the formulas in Tabs 2–3 calculate automatically, and run the 15-minute weekly agenda against the dashboard in every team meeting.
