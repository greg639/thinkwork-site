Demo Pacing & Length Calculator

A six-step worksheet that calculates recommended demo length and section-by-section pacing based on deal stage, deal size, and stakeholder count.

How to use it

Run through the six steps before you build your storyboard to get a target total length and section-by-section time budget for this specific deal, then use the totals to set your Demo Storyboard's time column.

What's inside

  • Base-minutes table by demo type/deal stage
  • Deal size adjustment table (SMB/mid-market/enterprise)
  • Stakeholder count adjustment table with a capped maximum
  • Composition adjustments (exec sponsor, cross-functional committee, quick-overview request)
  • Section pacing percentage breakdown (opening through close)
  • Fully worked example calculation with time budget

Use this worksheet to calculate recommended demo length and section-by-section pacing before you build the storyboard. Takes under 2 minutes.

Worked Example

Second demo (deep-dive) for a mid-market account, 4 stakeholders, no executive sponsor, single department:

  • Base: 45 min
  • Deal size (Mid-market): +5 min
  • Stakeholders (4 → +5 min)
  • Composition: +0
  • Total = 55 minutes

Section breakdown for 55 minutes:

  • Opening: ~3 min
  • Recap & agenda: ~5.5 min
  • Core demo: ~27.5 min
  • Proof & validation: ~8 min
  • Q&A: ~8 min
  • Close: ~3 min

Rule of Thumb

If your calculated total exceeds 60 minutes, that's a signal to split into two shorter, more focused sessions rather than run one long demo, attention and retention drop sharply past the 45–50 minute mark regardless of deal size.
