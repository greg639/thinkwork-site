Week 1 (Days 1–5): Foundation

  • Day 1: Read LinkedIn Outreach Brand & Compliance Guide; complete Cold Outreach Readiness Quiz cold (baseline, not for scoring against yet)
  • Day 2: Shadow 3+ live or recorded calls; review ICP and product problem list with manager
  • Day 3: Shadow 2 more calls; draft first cold email using the PAS-R framework (not sent)
  • Day 4: Manager reviews the draft against the Cold Email Copy Review Scorecard; revise
  • Day 5: Practice LinkedIn comments using the Comment & Engagement Scripts on 5 real posts (no outreach yet); first 10 supervised dials

Week 2 (Days 6–10): Guided Build

  • Build first prospect list with manager, applying the Cold Outreach Readiness Quiz targeting section
  • Choose channel mix per account using the Channel Mix Decision Framework
  • Draft full sequence (8–12 touches); manager runs the Outbound Sequence Audit Checklist before it goes live
  • Begin logging activity daily in preparation for the Weekly Prospecting Activity Scorecard

Week 3 (Days 11–15): Guided Execution

  • First sequence goes live under daily manager spot-check
  • Retake the Cold Outreach Readiness Quiz against the live list and draft before any list expansion
  • First full week tracked on the Weekly Prospecting Activity Scorecard
  • Daily objection-handling drill using the top 3 scripted responses

Week 4 (Days 16–20): Independent Ramp Checkpoint

  • Run the Week 4 section of the SDR Outbound Ramp Skills Checklist as a formal review with manager
  • Any unchecked item becomes the specific coaching focus for the following two weeks
  • Begin second sequence with reduced manager oversight

Days 21–30: Full Independent Cycle

  • Operate 2+ live sequences with only weekly (not daily) manager review
  • Weekly Prospecting Activity Scorecard reviewed in 1:1 using its standard review questions
  • Prepare for Week 8 ramp checkpoint against the SDR Outbound Ramp Skills Checklist

How to use it

Hand this to a new SDR on day 1 alongside the 9 component resources it bundles, work through the tracker table week by week with their manager, and use the Week 4 checkpoint against the SDR Outbound Ramp Skills Checklist before declaring them independently ramped.
