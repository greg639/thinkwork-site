New Rep Pre-Boarding Checklist

What to read, request, and set up before day one, so a new rep's first week builds momentum instead of paperwork fatigue.

What's inside

  • Admin & access items to close out before day 1
  • 6 required pre-reads to complete before day 1
  • Tooling setup checklist (CRM, dialer, LMS, comms)
  • Meet-before-day-1 scheduling items
  • Self-directed reflection items including a baseline skill assessment
  • A parallel manager checklist so prep happens on both sides

Send this the day the offer is signed. Everything on it should be done before day 1 — day 1 itself should start with selling-adjacent work, not IT tickets.

Admin & access (owned by HR/Ops, confirm 5 business days before start)

  • Offer letter and background check fully closed out
  • IT ticket submitted for laptop, email, CRM, dialer, and comms tool access
  • Payroll, benefits, and equity paperwork submitted
  • Manager has confirmed the day-1 agenda and sent it to the new rep by end of the prior week

Read before day 1

  • Company one-pager / elevator pitch
  • Most recent board deck or all-hands recording (redacted if needed)
  • Top 3 competitor battlecards
  • Ideal customer profile (ICP) definition
  • Current quarter's sales priorities / OKRs
  • Product demo recording (30–60 min)

Set up before day 1

  • CRM login tested, personal pipeline view configured
  • Dialer / meeting-recording tool installed and tested
  • Enablement platform / LMS account activated
  • Joined relevant Slack/Teams channels: team channel, wins channel, competitive-intel channel

Meet before day 1

  • 15-minute intro call scheduled with manager for day-1 morning
  • Buddy/mentor assigned and introduced before day 1
  • Week-1 intro calls scheduled with: sales engineering, marketing, customer success, and one top-performing peer

Reflect before day 1 (self-directed)

  • Complete a baseline Skill Mastery Self-Check Quiz — so week-1 coaching starts from real data, not guesswork
  • Write down 2 things you want to be true about your role in 90 days
  • List prior sales training/certifications so your manager can skip what's redundant

Manager's parallel checklist

  • Pre-brief written for the rep's first 2 weeks (shadow schedule, first live call date)
  • Existing pipeline/territory ready to hand off on day 1, if applicable
  • First coaching 1:1 pre-scheduled for the end of week 1

How to use it

Send this to the new hire the day the offer is signed, and run the manager checklist in parallel so day 1 starts with a scheduled first call, not a laptop-configuration afternoon.
