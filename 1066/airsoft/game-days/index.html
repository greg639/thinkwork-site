When we play

Game days

We run by prior booking, on weekends. We usually need two weeks notice, but will be as flexible as we can.

The running order

How the day goes

Gates open08:00 to 09:00
ChronoFrom 08:30
Safety briefing09:30 to 10:00
Luncharound 12:30, for about 45 minutes
We closearound 15:30

Rental players should arrive at 08:30. Go straight to reception to sign in before unloading.
