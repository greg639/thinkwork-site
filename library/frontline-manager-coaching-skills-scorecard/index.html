Frontline Manager Coaching Skills Scorecard

A rubric that rates a manager's own coaching behaviors: preparation, diagnosis, evidence, follow-through: against the techniques that actually move rep skill development, not their reps' output.

How to use it

Have the manager self-score against a recent coaching session recording, then have a skip-level or peer manager independently score the same recording, any 2+ point gap on a criterion is the coaching skill to work on first.

What's inside

  • 10 rated coaching-behavior criteria, 1-4 scale each
  • Behavioral descriptors for Not Yet / Developing / Proficient / Advanced at each criterion
  • Criteria covering prep, diagnosis accuracy, evidence use, and reinforcement balance
  • Criteria covering commitment-setting, follow-up, and documentation
  • A career/role/results relevance check specifically for the manager's coaching language
  • Total scoring band (10-40) with interpretation
  • Self-rating plus a required corroboration method (recording review by skip-level or peer manager)
  • A quarterly re-score cadence

This scorecard rates the manager's own coaching behavior: not the rep's performance, not the rep's deal outcomes. A manager can have a top-performing rep and still be coaching badly (the rep is succeeding despite the coaching, not because of it). Score against a real, recent coaching conversation, live or recorded.

How to score this without fooling yourself

  1. Self-rate first, against a specific coaching session you can point to (ideally recorded).
  2. Have a skip-level or peer manager independently score the same session using this same rubric.
  3. Any criterion with a 2+ point gap between self-score and reviewer score is where the manager has a blind spot, not the lowest raw score.
  4. Re-score quarterly against a fresh session, not the same one, to confirm the behavior actually generalized.
