Deal Slippage Analysis Template

Trace every pushed close date across a quarter back to its real root cause: budget, champion loss, competition, or process gap, using a fixed taxonomy instead of a vague "pushed to next quarter" note.

How to use it

Log every slip the moment it happens using the Slip Interview questions, tag it with a root cause code, and run the quarterly rollup at quarter-end to find your top 3 systemic causes instead of treating each slip as a one-off.

3. The Slip Interview, 5 Questions to Ask the Moment a Close Date Moves

  1. What specifically changed on the buyer's side between when this date was set and now?
  2. Was there a mutual action plan in place with dated steps: and if so, which step broke first?
  3. Is the original champion still actively engaged, and do they still have the influence they had at deal start?
  4. Has a new stakeholder, competitor, or budget conversation entered the picture since the last forecast call?
  5. Is this a timing slip (still closing, just later) or a qualification slip (this was never a real opportunity)?

5. Mutual Action Plan (MAP) Checklist: Prevents the Next Slip

  • Every stakeholder involved in the decision is named (not just "the team will review")
  • Every remaining step has an owner and a date, not just a description
  • The close date is confirmed by the buyer, not just set by the rep
  • Budget approval status is confirmed in writing, not assumed
  • A defined "what happens if this step slips" contingency exists for every step on the critical path
