Sales Coaching Plan Template (30-60-90)

A quarter-long coaching roadmap tying each 30-day block to a named skill, a practice method, and a measurable outcome.

How to use it

Fill in one skill/practice/outcome block per 30-day period at the start of the quarter, review progress against the measurable outcome at each check-in date, and use the end-of-quarter review to seed the next plan.

What's inside

  • Plan overview with baseline starting point and overall quarter goal
  • Days 1-30 block: named skill, practice method checklist, measurable outcome
  • Days 31-60 block: named skill, practice method checklist, measurable outcome
  • Days 61-90 block: named skill, practice method checklist, measurable outcome
  • Coaching cadence and check-in date per block
  • End-of-quarter review with carry-forward field for the next cycle

A quarter-long roadmap, not a to-do list. Each block names one skill, one practice method, and one measurable outcome, so coaching compounds instead of repeating the same generic advice every month.

Plan overview

  • Rep: [Name]
  • Manager/coach: [Name]
  • Plan period: [Start date]: [End date, ~90 days]
  • Overall goal for the quarter: [1 sentence: the outcome this whole plan is building toward]
  • Starting baseline: [current skill level, recent call scores, or quota attainment, the honest starting point]

Days 1–30

  • Named skill focus: [e.g., "Quantifying pain in discovery calls"]

  • [e.g., Role-play the pain-quantification sequence 2x/week with manager]

  • [e.g., Call review after every discovery call this month, scored on this skill only]
