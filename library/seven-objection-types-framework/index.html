The 7 Objection Types Every Rep Must Recognize

The foundational taxonomy: Price, Timing, Authority, Need, Trust, Competition, and Procrastination: that every other resource in this library is built on, so reps can name the real objection type before they respond.

How to use it

Train new reps on this taxonomy before teaching any rebuttals, and have experienced reps silently categorize each objection by type in real time before choosing a response.

What's inside

  • The full 7-type taxonomy: Price, Timing, Authority, Need, Trust, Competition, Procrastination
  • Verbal tells / example phrases for recognizing each type in real time
  • The root cause behind each type's surface phrasing
  • A strategic response principle for each type
  • Common misdiagnosis warnings so reps don't apply the wrong lever
  • An explanation of why misapplied rebuttals actively push deals further away

Every objection a rep will ever hear collapses into one of seven types. Reps who treat objections as infinite and improvise are always a step behind; reps who can name the type in real time know exactly which strategic lever to pull. This taxonomy is the foundation every other resource in this library is built on.

1. Price

Definition: Resistance rooted in cost relative to perceived value, not necessarily actual affordability. Verbal tells: "It's too expensive." "You're pricier than X." "We don't have budget." Root cause: Value hasn't been established at a level that justifies the number, this is a value gap wearing a price costume. Strategic response principle: Never discount first. Diagnose whether it's a budget ceiling or an unconvinced-of-value problem before responding. Common misdiagnosis: Treated as a hard budget constraint when it's actually a value objection, leading reps to discount when they should instead build the case.

2. Timing

Definition: Resistance based on when to act, not whether to act. Verbal tells: "Not a priority right now." "Call me next quarter." "We're mid re-org." Root cause: Something else is genuinely competing for attention, or the trigger event hasn't happened yet. Strategic response principle: Find out what would need to be true for timing to shift, and secure a specific, dated follow-up rather than an open-ended "later." Common misdiagnosis: Treated as a firm no when it's often a genuine "not yet", reps give up instead of scheduling a real re-engagement.

3. Authority

Definition: Resistance because the person on the call isn't the one who can say yes. Verbal tells: "I'm not the decision maker." "I need to loop in my boss/the board." "Send me something I can forward." Root cause: The buying committee or approval chain hasn't been mapped, or the current contact lacks internal influence. Strategic response principle: Turn the contact into an equipped internal champion rather than treating this as a dead end, arm them with what they need to sell it internally. Common misdiagnosis: Treated as a stall when it's a legitimate structural fact, reps push harder on the wrong person instead of multi-threading.

4. Need

Definition: Resistance because the prospect doesn't yet believe the problem is real, urgent, or theirs to solve. Verbal tells: "I don't see the problem you're describing." "We built something similar in-house." "This seems like overkill." Root cause: The pain hasn't been made concrete and personal, it's still abstract or hypothetical to them. Strategic response principle: Use specific, workflow-level questions to make the cost of the status quo tangible, rather than restating your value prop louder. Common misdiagnosis: Treated as "wrong prospect, move on" when it's actually a discovery gap, the rep skipped the work of making the pain concrete.

5. Trust

Definition: Resistance rooted in doubt about the vendor, the category, or the rep, not the specific offer. Verbal tells: "How did you get my info?" "We tried something like this before and it failed." "I need to see more proof." Root cause: Either a bad past experience (with your category or a competitor) or insufficient social proof/credibility established so far. Strategic response principle: Address with specificity and relevant proof (same industry, same use case): generic reassurance makes trust objections worse, not better. Common misdiagnosis: Treated as a feature or price objection when the real issue is unresolved skepticism about the vendor itself.

6. Competition

Definition: Resistance because the prospect is genuinely comparing you against one or more named alternatives. Verbal tells: "We're also evaluating [Competitor]." "How is this different from X?" "They're offering it cheaper/free." Root cause: A real, active multi-vendor evaluation is underway. Strategic response principle: Get explicit about decision criteria rather than competing blind, ask what would make each option the easy yes or easy no. Common misdiagnosis: Treated as a price objection when the real question is which vendor best fits specific, nameable criteria.

7. Procrastination (Stalling)

Definition: Resistance that isn't really about any single factor, it's a generalized avoidance of the decision itself. Verbal tells: "I need to think about it." "Let's revisit next quarter." "Send me the contract, I'll get to it." Root cause: Almost always a proxy for one of the other six types that hasn't been isolated yet: decision fatigue, unresolved fear, or an objection the prospect hasn't voiced. Strategic response principle: Never accept this at face value, isolate which of the other six categories is actually hiding underneath it before responding. Common misdiagnosis: Treated as its own standalone objection requiring a "closing trick," when the actual fix is diagnostic questioning to surface the real category underneath.

Why This Taxonomy Matters

Every "clever rebuttal" fails if it's aimed at the wrong category: a trust objection answered with a price discount, or a procrastination stall answered with more features, actively pushes the deal further away. Train your team to silently categorize before responding: name the type, then reach for the matching strategic principle above.
