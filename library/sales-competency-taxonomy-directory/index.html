Sales Competency Taxonomy Directory — 400+ Skills Indexed

A browsable, coded index of 100 core sales competencies across Prospecting, Discovery, Negotiation, and Account Growth — each indexed at 4 mastery levels for 400+ total addressable directory entries.

What's inside

  • The indexing system: 100 core competencies × 4 mastery levels (Foundational / Proficient / Advanced / Expert) = 400+ entries
  • 25 coded competencies under Prospecting & Pipeline Generation (PROS-01 to PROS-25)
  • 25 coded competencies under Discovery & Qualification (DISC-01 to DISC-25)
  • 25 coded competencies under Negotiation & Deal Control (NEG-01 to NEG-25)
  • 25 coded competencies under Account Growth & Expansion (GRO-01 to GRO-25)
  • 4 fully worked examples showing all 4 mastery levels written out for a sample competency in each domain
  • A lookup-by-code convention so any team can cite a specific skill unambiguously (e.g. in job reqs, coaching notes, or interview guides)
  • Guidance on how to select a working subset (15–30 competencies) rather than deploying all 400+ at once

400+ skills indexed. The directory is built from 100 core, named competencies across four domains. Each core competency is indexed at four mastery levels — Foundational, Proficient, Advanced, Expert — giving 400+ addressable, lookup-able skill entries. Use the codes (e.g. DISC-07) to reference a specific skill unambiguously in job descriptions, coaching notes, interview guides, or a competency framework of your own.

How the indexing works

Every core competency below expands into four entries:

LevelWhat it means
FoundationalExecutes with a script/checklist and close supervision
ProficientExecutes independently, consistently, without prompting
AdvancedAdapts the skill to non-standard situations; coaches others in it
ExpertSets the standard others are trained against; visible org-wide impact

Worked example (DISC-07, Qualification Framework Application):

  • Foundational — Can complete a qualification framework's fields (e.g. MEDDIC, BANT) when prompted, post-call, from notes.
  • Proficient — Qualifies live, in-call, without notes, and disqualifies appropriately.
  • Advanced — Adapts the framework when a deal doesn't fit the standard shape (e.g. no clear economic buyer yet) and still reaches an accurate qualification call.
  • Expert — Has revised or authored the org's qualification framework itself based on patterns seen across hundreds of deals.

Apply this same 4-level expansion to any competency below.

Using the directory without deploying all 400+

Most teams should pick 15–30 competencies (a mix across all four domains) as their first working framework — enough to differentiate performance without overwhelming managers doing observation-based coaching. Use this directory as the master reference to select from, and expand into new codes only when a gap in coaching or hiring conversations keeps surfacing that isn't covered.

How to use it

Select 15–30 codes across the four domains as your working competency set, write out the 4 mastery levels for each using the worked example as a template, then use the codes consistently across job descriptions, interview guides, and coaching notes so everyone means the same thing by "negotiation skill."
