Prospecting Competency Rubric (S-SEA Aligned)

A five-level mastery rubric across the four core prospecting competencies: research, messaging, cadence design, and channel fluency, for grading rep skill level with real evidence and building a targeted development plan.

How to use it

Score each rep against the four dimensions using the level descriptors as evidence anchors, then build a targeted development plan from the gaps instead of giving generic "do more outreach" coaching.

What's inside

  • The 4 prospecting competency dimensions defined
  • 5 mastery levels (Novice through Expert) with clear distinguishing criteria
  • Full 4x5 behavioral rubric matrix with concrete evidence-based descriptors
  • Role-readiness map (what level a new SDR vs. senior AE should be at)
  • Self-score vs. manager-score calibration rule
  • An individual development plan template tied directly to rubric gaps
  • Guidance on pairing this rubric with the SSI Tracker and Coaching Guide

Aligned to the S-SEA five-level mastery convention: Novice → Developing → Competent → Advanced → Expert: applied across the four competencies that make up real prospecting skill: Research, Messaging, Cadence Design, and Channel Fluency.

Role Readiness Map

Role / TenureExpected Level
New SDR (0–3 months)L1–L2 across all dimensions; target L2 by end of ramp
Ramped SDR (3–9 months)L3 across all dimensions
Senior SDR / AE running own pipelineL3–L4, at least one dimension at L4
Team lead / enablement / managerL4–L5, expected to coach others at L3

Scoring Instructions

  1. Self-score each dimension 1–5 using the descriptors above as evidence anchors, not gut feel.
  2. Manager scores independently, using real evidence: call recordings, actual sequences sent, CRM notes, message drafts.
  3. If the gap between self-score and manager-score is more than 1 level, discuss the evidence discrepancy directly, don't just average the two numbers.
  4. Use the lower of the two scores as the "official" level unless the manager's evidence supports the higher one. This avoids grade inflation.
