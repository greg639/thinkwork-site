CRM Hygiene Cheat Sheet for New Reps

The exact CRM fields to update, in order, within 15 minutes of every call — with a copy-paste notes template and good-vs-bad examples — so bad habits never get the chance to form.

What's inside

  • The 15-minute rule
  • 6-step field-update order for every call
  • Verbatim call-notes structure template
  • Good vs. bad note examples side by side
  • End-of-day 5-point CRM check
  • Table of common bad habits and what they cause

Bad CRM habits form in the first two weeks and are almost impossible to unlearn after that. This is the exact order to update fields after every single call — do this from day one and it never becomes a problem.

The Rule

Update the CRM within 15 minutes of the call ending — not at the end of the day, not at the end of the week. If you wait, you'll misremember details and start writing lazy, useless notes. Set a timer if you have to.

The Exact Field Order (Every Call, No Exceptions)

1. Call outcome / disposition (first, before anything else)

Select the correct disposition from your CRM's list (e.g., Connected — Discovery, Connected — Demo, No Show, Voicemail, etc.). This drives your activity reporting — get it right immediately or your metrics lie about your week.

2. Next step + date (before you write a single note)

Set the follow-up task with a specific date, not "soon" or "next week." If there's no next step because the deal is dead, mark it dead now — don't leave a zombie deal sitting in an active stage.

Good: Task: "Send pricing doc + follow up call" — Due: Thursday 3pm Bad: Task: "Follow up" — Due: (blank)

3. Deal stage (update it, don't leave it stale)

Move the stage forward or backward to match reality, even if it's uncomfortable to move it backward. A stage that hasn't moved in 3+ weeks is either dead or mis-staged — fix it, don't ignore it.

4. Call notes — use this exact structure, every time

`` SITUATION: [1 line — what's their current setup/process] PROBLEM: [1 line — what they said is broken/painful] IMPACT: [1 line — the cost/consequence they named] STAKEHOLDERS: [names + roles of everyone mentioned, not just who was on the call] OBJECTIONS RAISED: [verbatim if possible] COMPETITION MENTIONED: [name if any, "none mentioned" if not] NEXT STEP: [what + who + by when] ``

Good example:

SITUATION: Using spreadsheets to track team pipeline, updated manually by each rep. PROBLEM: No visibility for manager until Friday rollup; numbers often stale. IMPACT: Manager says they've missed forecasting misses twice this quarter because of it. STAKEHOLDERS: Sarah (Sales Ops Mgr, on call), mentioned "VP Dave" as final approver. OBJECTIONS RAISED: "We tried a tool 2 years ago, team didn't adopt it." COMPETITION MENTIONED: none mentioned. NEXT STEP: Send 2-pager on adoption/rollout approach by Wed; book intro call w/ Dave next.

Bad example (do not do this):

"Good call, seems interested, will follow up."

5. Update the contact/account record (not just the opportunity)

  • Add any new stakeholder names + titles you learned, even if they weren't on the call
  • Update contact's role/title if it's changed or was wrong
  • Log the correct next renewal/budget-cycle date if you learned it — this is gold for future you

6. Tag/flag anything a teammate would need if they inherited this deal tomorrow

Ask yourself: "If I got hit by a bus tonight, could a colleague pick this deal up from my notes alone tomorrow morning?" If not, add the missing piece before you close the tab.

The 5-Minute End-of-Day CRM Check

Before you log off, not before you start tomorrow:

  • Every call today has a disposition set
  • Every call today has a next step with a real date
  • No deal is sitting in a stage that doesn't match reality
  • No task due today is still showing as open
  • Tomorrow's calendar reflects everything booked today

Common Bad Habits This Prevents

Bad habitWhat it causes
Batch-updating CRM once a weekNotes become vague, deals get mis-staged, forecasts lie
Skipping stakeholder names because "I'll remember"You won't, three deals later
Leaving dead deals in active stagesInflated pipeline, bad forecast accuracy, awkward conversation with manager later
Writing notes only you can decipherNobody can cover for you, and future-you can't either
Setting vague next-step tasks ("follow up")Tasks get skipped because there's no real trigger date

How to use it

Follow the six-field order after every call for your first month, using the note structure template until it becomes automatic.
