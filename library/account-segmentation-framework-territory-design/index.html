Account Segmentation Framework for Territory Design

A weighted A/B/C tiering model — scored on fit, intent, whitespace, and strategic value — that tells reps exactly where to spend prospecting hours instead of treating every account equally.

What's inside

  • Definition of the three tiers: A-Strategic, B-Core, C-Long-tail
  • Weighted scoring criteria: firmographic fit, intent signals, whitespace/expansion, strategic value
  • Point-based scoring formula with stated weights
  • Tier-boundary score ranges
  • Time-allocation table per tier (touches per week, channels)
  • Fully worked example scoring an account
  • Re-tiering cadence and trigger-driven exceptions

Why tiering matters

Every account in a territory looks equal on a spreadsheet until you score it. Without a tiering model, reps default to spending equal time everywhere — which means your best-fit, highest-potential accounts get the same 20 minutes a week as accounts that will never close. This framework forces the time allocation to follow the scoring, not the rep's gut feel.

The three tiers

  • Tier A — Strategic: Best-fit accounts with the highest revenue potential and clearest intent signals. Small in number, largest in allocated time.
  • Tier B — Core: Solid fit, moderate potential, standard cadence. The bulk of the territory sits here.
  • Tier C — Long-tail: Fits the ICP on paper but low near-term potential or weak signals. Light-touch, automated-leaning cadence.

Scoring criteria (score each account 1–5 per criterion)

CriterionWeight1 (weak)5 (strong)
Firmographic fit — industry, company size, tech stack match to ICP30%Poor match on 2+ ICP dimensionsMatches all core ICP criteria
Intent signals — recent trigger events, content engagement, inbound activity25%No recent signal detectedActive trigger event or inbound engagement in last 30 days
Whitespace / expansion potential — number of relevant departments, teams, or use cases not yet penetrated25%Single-use-case, no expansion pathMultiple departments/use cases, clear expansion path
Strategic value — logo value, reference potential, existing relationship strength20%No relationship, low reference valueExisting champion or high reference/logo value

Calculating the tier

Weighted score = (Firmographic × 0.30) + (Intent × 0.25) + (Whitespace × 0.25) + (Strategic value × 0.20)

Maximum possible score: 5.0

Weighted scoreTier
4.0 – 5.0A — Strategic
2.5 – 3.9B — Core
Below 2.5C — Long-tail

Tier% of accounts (typical)Touches per weekChannels

C25–35%Automated/light-touchNurture sequence, quarterly check-in, marketing-qualified handoff

Worked example

Account: Mid-market logistics company, 340 employees

  • Firmographic fit: 5 (exact ICP match on size and industry)
  • Intent signal: 4 (posted 2 relevant job openings in the last 3 weeks)
  • Whitespace: 3 (one department using a competing tool, two others untouched)
  • Strategic value: 3 (no existing relationship, moderate reference potential)

Weighted score = (5×0.30) + (4×0.25) + (3×0.25) + (3×0.20) = 1.5 + 1.0 + 0.75 + 0.6 = 3.85 → Tier B, borderline A

Recommendation: place in Tier A time allocation for one quarter given the active intent signal, then re-score.

Re-tiering cadence

Re-score every account quarterly, or immediately when a major trigger event occurs (funding, leadership change, M&A — see the Trigger-Event Prospecting Guide). A Tier C account with a fresh trigger event can jump to Tier A overnight; don't wait for the quarterly cycle to react to it.

How to use it

Score every account in the territory against the four weighted criteria, sort by weighted score into A/B/C, then set each rep's weekly touch plan using the time-allocation table rather than an even split.
